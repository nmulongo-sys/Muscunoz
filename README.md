# Muscunoz — Carnets de musculation

Deux applications HTML autonomes (données dans Supabase, copie locale dans le navigateur) :

- **Carnet de Charge** (`carnet-de-charge.html`) — reprise, surcharge progressive, objectif daté (Chemin de Stevenson).
- **Carnet Crawl** (`carnet-crawl.html`) — force de soutien pour nageuse.

Publiées sur GitHub Pages. Ouvrir un carnet puis « Ajouter à l'écran d'accueil ».
